# ローカル広告ブロック（Android）

ローカルVPNと端末内で生成したCA証明書を使い、**許可リストに書いた広告だけを表示して、それ以外の広告はすべてブロックする**Androidアプリです。通信は端末の外のサーバーを経由しません。

## しくみ

```
各アプリ ──DNS問い合わせ──▶ ローカルVPN(tun) ──▶ 広告ドメインなら NXDOMAIN を返す
   │                                          それ以外は実際のDNSへ転送
   └─HTTP/HTTPS──▶ ローカルプロキシ 127.0.0.1:8899（VPNが setHttpProxy で配布）
                       ├ CONNECT の時点でドメインを判定 → 広告なら 403
                       ├ HTTPS検査ON：端末内CAで TLS を復号し URL 単位で判定 → 広告なら 204
                       └ 許可リストに一致したものは必ず通す
```

判定の優先順位は **許可リスト ＞ ブロックリスト ＞ 素通し** です。

- VPNが受け取るのはDNSだけです（経路は仮想DNSサーバー宛ての1つだけ）。そのため他の通信の速度やバッテリーへの影響は小さく済みます。
- 上流サーバーの証明書は普通どおり厳密に検証します（ホスト名の一致も確認します）。
- CAは端末ごとにランダムに生成され、秘密鍵はアプリ専用の領域にしか保存されません（`allowBackup=false`）。

## ビルド

1. Android Studio（Ladybug 以降）でこのフォルダを開く
2. Gradle Sync（Gradle Wrapper は自動で生成されます）
3. 実機で実行（minSdk 29 = Android 10 以上）

依存ライブラリは BouncyCastle（証明書の生成用）だけです。

## 使い方

1. **購読するフィルタリスト** → 「保存してダウンロード」（EasyList・AdGuard日本語フィルタなど）
2. **CA証明書を保存** → **設定を開く** → 暗号化と認証情報 → 証明書のインストール → CA証明書 → `ダウンロード/LocalAdBlock-CA.crt`
3. 「開始」をタップして、VPN接続を許可する
4. 表示したい広告を **許可リスト** に書いて保存する（動作中でもすぐに反映されます）

### 許可リストの書き方

```
good-ads.example                     # ドメインごと許可（サブドメイン含む）
||ad.my-favorite-site.jp^            # 同上（Adblock Plus 形式）
||ads.example.com/partner/*          # 特定URLだけ許可（HTTPS検査ONのとき）
```

## 制限事項（重要）

| 項目 | 内容 |
|---|---|
| ユーザーCAを信頼するアプリ | Android 7以降、アプリは既定で「ユーザーが入れたCA」を信頼しません。**HTTPSの中身まで検査できるのは主に Chrome などのブラウザ**です。それ以外のアプリはTLSのハンドシェイクで失敗するので、そのホストは自動でバイパスに登録されて、次からは素通しになります（ドメイン単位のブロックは引き続き効きます）。 |
| 初回の失敗 | 自動バイパスに登録される前の最初の1回だけ、そのアプリの通信が失敗することがあります。 |
| プロキシを使わないアプリ | システムのプロキシを無視するアプリには、DNSによるドメイン単位のブロックだけが効きます。 |
| プライベートDNS | 設定の「プライベートDNS」が「ホスト名を指定」になっていると、DNSブロックを迂回されることがあります。「自動」か「OFF」にしてください。 |
| DNS over HTTPS | ブラウザ内蔵の「セキュアDNS」も迂回の原因になります（Chromeならプロキシ経由になるので、HTTPS検査側で判定されます）。 |
| HTTP/2・HTTP/3 | 検査中の通信は HTTP/1.1 に落として処理します。QUIC(HTTP/3)はプロキシを通らないので、DNSブロックだけが効きます。 |
| フィルタ構文 | `##` の要素隠し、正規表現ルール、`domain=` などのオプション付きルールには対応していません（誤ブロックを避けるため読み飛ばします）。 |
| 性能 | URLルールは1件ずつ照合しているので、大きなリストを入れると1リクエストあたり数ミリ秒かかることがあります。 |
| 配布 | Google Play のポリシーでは、他のアプリの広告を妨げるアプリや VpnService の使い方に制限があります。個人での利用（APKの直接インストール）を前提にしています。 |

## セキュリティ上の注意

- このCAを入れた端末では、このアプリがHTTPS通信を復号できる状態になります。使わなくなったら、設定の「ユーザー証明書」からCAを削除してください。
- 銀行・決済・ログインなどは、「HTTPS検査をしないドメイン」に追加しておくことをおすすめします。
- プロキシ（127.0.0.1:8899）は端末内の他のアプリからも接続できます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `AdBlockVpnService.kt` | ローカルVPN・DNSフィルタ・通知 |
| `MitmProxy.kt` | HTTP/HTTPSプロキシ・TLS終端・URL判定 |
| `CertificateAuthority.kt` | CAの生成と、ホストごとの証明書の発行 |
| `FilterEngine.kt` | ブロックリスト・許可リストの判定 |
| `RuleStore.kt` | リストの保存・購読リストのダウンロード・バイパス管理 |
| `Packets.kt` / `Http.kt` | IPv4/UDP/DNS・HTTP の解析 |
| `MainActivity.kt` | 設定画面 |
